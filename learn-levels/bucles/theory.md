# MANUAL // UNIDAD 4: BUCLES, MUESTREO Y TEMPORIZACION

## 4.1 Bucle Determinado (`for`)
Utilizado para procesar ventanas de muestras de longitud conocida y barridos temporales.

## 4.2 Espera Activa / Polling (`while`)
Ejecuta comprobaciones repetitivas hasta que un registro de hardware o condición física se cumpla.

## 4.3 Control de Flujo Interno (`break` y `continue`)
- `continue`: Descarta muestras corruptas o valores fuera de rango sin detener el proceso.
- `break`: Aborta el bucle inmediatamente al detectar una condición de fin de trama.
